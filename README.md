# Dark Matter Rotation Curve Simulator

This repository contains scripts to probe my dark matter model. Basically, it posits a new field, likely one that is not modeled in QFT. I treat it here completely classical. In this model the mass of the field surrounding a baryon is equal to its emission rate P, (in watts lol) times the time it takes to get (half) way to the nearest other baryon. This has the effect of making the field impossible (or hard) to measure in the lab, as it only starts to add up in rarefiled gases, on a percentage basis of the baryon mass. It is also assumed that this relationship breaks down at some distance (which seems to be in the cm range). In my first stab on FIRE data P = 30 watts (yes per baryon!!!) and a cut off density of 2e-4 / cm^3. These numbers are adjustable in the code.
